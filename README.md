# AI Resume Intilligence

## Overview

AI Resume Intelligence is an AI-powered platform that helps job seekers analyze, improve, and optimize their resumes.

Users can upload their resume, receive an AI-Powered analysis, identify missing skills, evaluate ATS compatibility, and compare their resume against specific job description.

The platform combines AI analysis with a structured scoring and job matching system to provide actionable feedback instead of just generating a generic score.

## Features

- User authentication
- Resume upload 
- Resume text extraction
- AI-powered resume analysis
- ATS compatibility analysis 
- Resume scoring 
- Skill detection
- Strength and weekness identification
- Missing skill detection
- Job description analysis
- Resume-to-job matching
- Job match score
- AI-powered improvement suggestions
- Resume versioning
- AI resume assistant/chat
